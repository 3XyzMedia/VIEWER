Что сделано:
1. Основа — проверенная пользователем v42, а не сломанная v43.
2. Удалён отдельный красный переключатель. Цвет текста — голубой градиент без чёрных участков (вариант v42).
3. Восстановлен прежний алгоритм MODEL → взрыв → бурлящее облако → текст и обратно, без новых пауз и последовательных эффектов.
4. Увеличен максимум диаметра взрыва с 3× до 6×; исходный 1.5× сохранён.
5. Сплаты исходной модели распределяются внутри мелкого радиуса вокруг 4096 опорных координат настоящей модели LABEL; это уменьшает наложение точек без увеличения шариков. Вершин/сплатов больше НЕ создаётся.
6. В текстовой фазе используется только МУЛЬТИПЛИКАТИВНОЕ уменьшение исходной матрицы mx. Никаких абсолютных огромных матриц.
7. Ошибка `label_color`: исходный v43 XML уже не содержал этой переменной, но ошибка могла приходить из кеша/иной сцены. v44 имеет новое имя шейдера xyz_fx44_safe_shader, все uniforms — float, `label_color` нигде в проекте нет.
8. Сохранены длительность MORPH, блокировка глобального Splat size и Screen minimum на время MORPH, мобильная рамка ~4.5 сек без голубого текста, FIRE, TOUR, SHARE.

ВАЖНО: Проверки исходников и ZIP не заменяют GPU-проверку на компьютере пользователя.
