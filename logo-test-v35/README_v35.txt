3XyzMedia STUDIO — MODEL MORPH v35 SINGLE SPLAT

Назначение: один плавный 3DGS MORPH, никакого ETHER / дополнительного ThreeJS 20K.

Основа: работающий krpano splatshader mode 9 из v23, сохранённый в v34.
Механика: ВСЕ исходные Gaussian-сплаты модели участвуют в одной траектории: source XYZ → локальный турбулентный взрыв → исходные LABEL target XYZ. Каждый сплат постепенно меняет исходный цвет на целевой, без отдельной красной системы, overlay и самостоятельных таймеров. На обратном пути всё восстанавливается.

Фазы прогресса в shader:
  Разлёт плавно 2%..36%, спадает 54%..95%.
  Сборка 25%..91%; эти интервалы перекрываются.
  Цвет меняется 31%..91%.
  Размер splat меняется 8%..91%.
Цикл кнопки MORPH: общий 5.7 сек, около 170 мс удержание готового текста, затем симметричный обратный путь.

Данные из другого Gaussian PLY не перечитываются, используются исходные вершины, уже загруженные krpano. Старый массив LABEL позиций из shader v23 — образец конечного текста.
Ограничение: количество конечных УНИКАЛЬНЫХ позиций соответствует исходной таблице LABEL (4096); при большем числе сплатов исходной модели координаты могут повторяться. Это не отдельный 20K-рендерер.

Файлы одной папки logo-test-v35 кладутся в VIEWER/.
Проверки: JS --check, XML parse, ссылки/содержимое ZIP.
Реальный рендер в krpano/WebGL у пользователя необходим для окончательной оценки.
