3XyzMedia v11 - REAL LABEL HD TEST

Папка для загрузки: VIEWER/logo-test-v11/
Внутри архива уже лежит папка logo-test-v11.

Что изменено:
- ПК MORPH переведён на 4096 целевых точек из настоящего LABEL_TEXTURE_RGB_3dgs.ply.
- Цвета для целевых точек берутся из реального Gaussian LABEL (через SH DC, как в v10).
- Геометрия целевого текста теперь тоже берётся прямо из реального label PLY, а не из прежней облегчённой текстовой заготовки.
- Мобильная сцена оставлена в SAFE-варианте: облегчённая процедурная надпись, чтобы не добивать WebGL на смартфоне.

Важно:
- Это тест на читаемость и производительность.
- На ПК текст должен читаться заметно лучше, чем в v10.
- На смартфоне чудес не обещает: мобильный режим intentionally облегчён.

Ничего из TOUR / VIDEO / MP3 / FIRE / основных настроек viewer специально не трогалось.
