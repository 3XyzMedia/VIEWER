3XyzMedia LABEL MORPH v12 MOBILE SAFE TEST

Прямая установка: архив содержит единственную готовую папку logo-test-v12.
Загрузить эту папку в корень VIEWER. Не смешивать с v11.

Исправлены две проблемы:
1. При открытии старой SHARE-ссылки с xml=scene_logo_v11.xml на смартфоне v11
   мог загружать ТЯЖЕЛУЮ десктопную сцену: регулярное выражение не учитывало v11.
   В v12 распознаются все тестовые XML v5-v12 и подставляется соответствующая
   сцена по типу устройства.
2. По нажатию на LABEL мобильный браузер запускал shader mode 9,
   после чего WebGL-контекст мог теряться. В v12 на мобильном mode 9
   не запускается. Вместо этого — лёгкая экранная анимация 3XyzMedia.
   Оригинальная модель остаётся видна; неоновый LABEL работает как раньше.

Ограничение: мобильный эффект НЕ является морфингом гауссианов.
На ПК сохранён предыдущий REAL LABEL HD: 4096 target XYZ/RGB.

Это безопасная диагностическая версия, чтобы убедиться, что причина падения — GPU MORPH,
а не исходная модель. Без тестирования на реальном телефоне нельзя гарантировать стабильность.
