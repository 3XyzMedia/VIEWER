3XyzMedia STUDIO + GPU MORPH 20K — v48
Дата: 25 октября 2026

ФАЙЛЫ:
 studio.html — исходная STUDIO со своими FX / TOUR / VIDEO / MP3, плюс кнопка GPU MORPH 20K.
 gpu-morph.html — проверенная пользователем логика v47 с 20 000 настоящими GPU-точками.
 LABEL_REAL_20000.xyz.bin — настоящие координаты LABEL из Blender.
 scene_logo_v46_fixed.xml и остальные файлы v46 — старый режим STUDIO, НЕ переписывать в GitHub отдельно.

ЧТО СДЕЛАНО:
- Из STUDIO кнопка «GPU MORPH 20K» открывает новый движок отдельной страницей. Она переносит адрес модели из поля PLY.
- Оба тяжёлых WebGL режима не работают одновременно. Возврат по «Вернуться в STUDIO».
- Большой обычный binary PLY читается оптимизированно: выборка 20 000 записей прямо из файла, без миллиона JS-объектов.
- В браузере запоминается обработанная модель в IndexedDB — при повторном запуске быстрее (зависит от настроек браузера).
- «Сохранить быстрый 20K» выгружает компактный исходник *.xyz20k, который можно загрузить как локальный файл на новом устройстве.
- По умолчанию GPU-режим показывает демо, затем загружает выбранную модель. Пользователь может выбрать локальный файл.
- Перевоплощение в красный/голубой текст, размер точек, разлёт, цикл, вращение сохранены из работающей v47.
- Большой GLSL-таблицы 20 000 if/else НЕТ. Старый эффект LAB «3XyzMedia» оставлен.

ОГРАНИЧЕНИЯ:
- GPU 20K — отдельный point-cloud рендерер, пока НЕ GPU Gaussian Splat внутри krpano.
- При переходе к GPU MORPH текущая krpano STUDIO закрывается; возврат назад открывает её снова.
- Локальный файл не может автоматически открываться другой страницей: нужно выбрать его через кнопку либо через кеш.
- GLB: базовый mesh без внешних текстур/Draco/Meshopt; OBJ/STL без материала; сжатые PLY экспериментально.
- Первая загрузка большой PLY зависит от сети, последующая быстрая при работе кеша.
- На настоящем GPU пользователя новый комплект не тестировался. v47 отдельно уже показал хороший текст 20K.

КАК ЗАГРУЗИТЬ:
1. Распакуй ZIP.
2. Загрузи папку logo-test-v48 целиком в корень VIEWER.
3. Открой https://3xyzmedia.github.io/VIEWER/logo-test-v48/studio.html
4. Нажми «GPU MORPH 20K» или сразу https://3xyzmedia.github.io/VIEWER/logo-test-v48/gpu-morph.html
5. Для тяжёлой модели один раз выбери локальный .PLY; затем при необходимости скачай готовый *20k.xyz20k файл.

Контекст: прежняя v47 была успешной по плотности текста на Buity_3dgs.ply (~400 081 вершин); исходный большой файл сюда не включён, так как не был приложен.
