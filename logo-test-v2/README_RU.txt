3XyzMedia LOGO MORPH v2 TEST

1. Создать папку VIEWER/logo-test-v2/
2. Загрузить в неё все файлы этого комплекта.
3. Нужен существующий krpano.js в корне VIEWER (не копировать).
4. Открыть https://3xyzmedia.github.io/VIEWER/logo-test-v2/studio.html
5. Дождаться загрузки SOY2; исходная камера и управление взяты из рабочей STUDIO v6.
6. Нажать LOGO MORPH, проверить, затем Вернуть.

Важно: 2048 точек-целей из исходных 32000. Это НЕ готовый полный LOGO MORPH и может быть тяжело для компилятора shader на смартфоне. Если модель исчезает/ошибка, остановить тест; STUDIO v6 не затронута.

В тесте используются файлы сцены scene_logo_v2.xml и GUI studio.html отдельно от основного VIEWER.
