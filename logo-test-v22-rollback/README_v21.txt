3XyzMedia v21 — DENSE DESKTOP LABEL 40 000

В ZIP готовая папка logo-test-v21 для корня VIEWER. НЕ смешивать с предыдущими папками.
На ПК используется реальный набор 40 000 позиций и цветов из LABEL_TEXTURE_RGB_3dgs.ply.
Они визуализируются отдельным WebGL-слоем поверх krpano; исходная модель плавно скрывается при формировании текста, затем возвращается.
Это не 1:1 преобразование исходных гауссианов; количество фиксировано 40 000 независимо от исходного PLY.
Качество для ПК зависит от GPU, масштаба и размеров точек.
На смартфоне сохранён мобильный CSS-неон из v20; там дополнительный WebGL не запускается.

В STUDIO сохраняются стандартные настройки масштаба, вращения X/Y/Z, смещения, размер MORPH-сплатов.
Параметры передаются через существующий механизм SHARE; v21 использует их для плотного текста при открытии на ПК.
Фирменная кнопка LABEL продолжает запускать анимацию; отдельный GPU слой не перехватывает клики.

ПРОВЕРКИ: Node --check, XML parse, пути на диске, размер бинарного буфера, наличие контролов.
ОГРАНИЧЕНИЯ: отдельный WebGL-контекст на ПК; синтаксические проверки не доказывают визуальную правильность или GPU совместимость.
Ничего в основном репозитории не меняется, пока пользователь сам не загрузит v21.
