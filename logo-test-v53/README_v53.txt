3XyzMedia STUDIO v53 — DIRECT GPU MORPH 20K / экспериментальная интеграция

Нет iframe, перехода по URL, демомодели и отдельного окна. Рисование 20K непосредственно в canvas studio.html, PLY берётся из поля STUDIO, Blender LABEL из LABEL_REAL_20000.xyz.bin. Используется WebGL2 GPU buffer + компактный shader.

Старый MORPH и панель его настроек сохранены. SHARE через gpu20k=1.

ОГРАНИЧЕНИЕ: для 20K исходные 20 000 точек нормализуются по bounding box; пространственная система крpano/видеокамеры и анимация на данном этапе НЕ синхронизированы. Это тест прототипа прямой интеграции, а не подтверждённое бесшовное преобразование сплатов. Во время эффекта исходные Gaussian-сплаты продолжают работать; наслаивание возможно. Реального GPU-теста нет.

Проверка: загрузить logo-test-v53 целиком в VIEWER, открыть https://3xyzmedia.github.io/VIEWER/logo-test-v53/studio.html и нажать MORPH 20K. Старая версия не перезаписывается.
