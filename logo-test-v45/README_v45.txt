3XyzMedia MORPH v45 — PACKED REAL LABEL 20K

Что изменено
- 20 000 реальных выборочных точек из LABEL_TEXTURE_RGB_3dgs.ply (80 100 вершин).
- Вместо огромного набора vec3-векторов координаты X/Z упакованы в 24-битные целые значения: по 12 бит на каждую ось.
- Глубина Y — тонкая процедурная прослойка: исходная координата Y из PLY НЕ сохранена; объёмный 3D текст лишь приближён.
- Оригинальные сплаты исходной модели не добавляются и не удаляются; число отрисованных сплатов по-прежнему равно числу в выбранной модели.
- Реальные 20k опорных координат используются независимо от количества исходных сплатов. При малом числе исходных сплатов весь набор может не заполниться.
- Подавлен широкий искусственный микроразброс предыдущей версии.
- Механика MODEL -> BURST -> LABEL -> MODEL, размеры сплатов и mobile-рамка наследуются от v44.

Установка: перенеси папку logo-test-v45 в корень репозитория 3XyzMedia/VIEWER.
GitHub Pages: https://3xyzmedia.github.io/VIEWER/logo-test-v45/studio.html

Ограничения: 20k координат НЕ означают 20k дополнительных сплатов. Данные 2D X/Z квантованы; цвет голубой; не гарантирована скорость/успешная компиляция без WebGL-теста на целевом GPU.

Проверки: XML синтаксически корректен, JS прошёл node --check, архив целый. Доступного WebGL-контекста в тестовом Chromium нет; компиляция на реальном GPU НЕ подтверждена. При первых признаках зависания закрой вкладку, не открывай многократно.
