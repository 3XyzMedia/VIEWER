3XyzMedia STUDIO v71 — независимый исходный фронт MORPH 20K

Основа: v70 COSMIC UI + исправление v70 SHARE MOBILE.

Исправлена конкретная ошибка: если зритель повернул исходную модель, то целевой текст 20K ранее также поворачивался и мог показываться задом наперёд.

Алгоритм:
- В редакторе запоминается исходный ракурс текста (углы камеры yaw/pitch).
- При старте 20K отдельно фиксируется текущий ракурс зрителя.
- В шейдере целевая фигура получает постоянную поправку между двумя ракурсами.
- На момент появления текста он ориентирован как был задан автором, даже если зритель повернул модель ДО запуска.
- После старта зритель может продолжить вращение: поправка остаётся постоянной, а поворот камеры работает, как раньше.
- Исходная модель и её положение/камера никогда автоматически не сбрасываются.
- Ползунки радиуса, цвета, перемешивания, MORPH, FX, TOUR и др. сохранены.

Интерфейс MORPH 20K:
- Добавлена кнопка «📌 Запомнить фронт 20K».
- При изменении X/Y/Z и положения текста вне анимации фронт запоминается автоматически.
- Параметры фронта передаются в SHARE: g71FrontYaw, g71FrontPitch.
- Старая SHARE-ссылка без этих полей берёт ракурс со старта страницы — обратная совместимость.

Дополнительно: в v71 включено мобильное исправление загрузки разных моделей из SHARE-ссылки, ранее подготовленное для v70.

ПРОВЕРКА:
1. Открыть Studio v71, настроить текст 20K лицом, нажать «Запомнить фронт 20K».
2. Выбрать галочку «передавать MORPH 20K», скопировать SHARE-ссылку.
3. Открыть её в другом окне, повернуть основную модель на 180°.
4. Нажать LABEL: текст должен появиться лицом, как при настройке.
5. Во время паузы на тексте вращать мышью: текст должен вращаться обычно.
6. По окончании исходная модель остаётся в текущем пользовательском ракурсе.
7. Проверить вторую модель по другой SHARE-ссылке на телефоне (мобильный 20K остаётся отключённым).

ОГРАНИЧЕНИЯ:
- Это математическая компенсация yaw/pitch GPU-слоя 20K, а не переписывание krpano-рендерера.
- Roll, pan, смена оси Up и сильные расхождения между krpano и GPU камерой ещё требуют визуального теста.
- Реальное тестирование WebGL в браузере не проводилось.
