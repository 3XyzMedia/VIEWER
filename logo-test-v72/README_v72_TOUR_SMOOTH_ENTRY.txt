3XyzMedia STUDIO v72 — TOUR SMOOTH ENTRY

ОСНОВА
STUDIO v71 TEXT FRONT LOCK TEST, подтверждена пользователем как работавшая.

ИСПРАВЛЕНИЕ
Ранее TOUR при запуске сразу переводил камеру на первую записанную точку, даже если зритель перед этим вращал/приближал модель.
Теперь TOUR запоминает текущий ракурс и плавно перемещает камеру к первой записанной точке. Затем выполняет прежний маршрут.

ТОЧНОЕ ПОВЕДЕНИЕ
- Подлёт к первой точке занимает столько же времени, сколько один отрезок TOUR: ползунок «Секунд на отрезок» (по умолчанию 5 с).
- При совпадении камеры с первой точкой дополнительный подлёт не добавляется.
- Углы интерполируются по кратчайшему повороту (в том числе 350°→10°), дистанция — без скачка зума, положение pivot/pan — плавно.
- Для режимов «останавливаться в точках» ON и OFF поддерживается тот же подлёт.
- Сохранённые TOUR-точки, SHARE-ссылки, кнопки «Стоп» и «Последнюю» не меняются.
- При повороте/масштабировании пользователем TOUR, как и раньше, прерывается.

ПУБЛИКАЦИЯ
Из ZIP загрузить ТОЛЬКО папку logo-test-v72 в 3XyzMedia/VIEWER.
Не изменять папки v70/v71 и старые ссылки.
Адрес после публикации: https://3xyzmedia.github.io/VIEWER/logo-test-v72/studio.html

ПРОВЕРКА
1. Создать и сохранить 2–3 точки TOUR (или открыть ссылку с записанным маршрутом).
2. Повернуть и увеличить модель, чтобы ракурс явно отличался от первой точки.
3. Нажать TOUR; камера должна не прыгнуть, а плавно приблизиться к точке №1, затем пройти по всему маршруту.
4. Проверить оба режима «останавливаться в точках».
5. Остановить TOUR на подлёте, повторно нажать TOUR: старт должен быть уже из текущего положения.
6. Проверить SHARE-ссылку с TOUR на другом устройстве.

ПРОВЕРКИ СБОРКИ
Проверка синтаксиса HTML-inline JS, прочих JS, ZIP, математики и моделирование кадров TOUR в Node выполнены.
Визуальное тестирование на реальном krpano/GPU пользователем пока не выполнено.
