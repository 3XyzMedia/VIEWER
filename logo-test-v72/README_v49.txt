3XyzMedia STUDIO v49 — GPU MORPH 20K (единый URL)

Что было неверно в v48:
- В оригинальном окне krpano оставался старый MORPH 4096 (голубой).
- Красный MORPH 20K был в другой странице; переход и SHARE не были интегрированы.
- Отдельная сохранённая модель 20K нужна только как необязательный способ ускорить загрузку.

Что исправлено в v49:
- Основная кнопка «MORPH 20K» использует GPU движок из v47/v48.
- Переход делается на ТОТ ЖЕ адрес studio.html, с параметром gpu=1; внутри появляется GPU-вид.
- Нажать «← STUDIO · Gaussian» — возврат к обычной krpano STUDIO на том же адресе.
- В разделе SHARE отмечай «Передавать GPU MORPH 20K по ссылке» и нажимай «Копировать ссылку»:
  получатель откроет studio.html?gpu=1&model=... с красным MORPH.
- Автор может указать SOY2.ply или HTTPS-адрес модели в обычной STUDIO перед переключением.
- Можно приписать &gpuautoplay=1, тогда цикл запускается после загрузки модели и LABEL.
- Старую кнопку LEGACY скрыли (коды оставлены для совместимости).
- Сохранился оригинальный 20K LABEL_REAL_20000.xyz.bin и WebGL2 динамический шейдер (без 20K if/else).
- Обработанные локально 20K точки сохраняются в браузерном кеше для повторного запуска.

ВАЖНО: Это режим GPU MORPH ВНУТРИ СТРАНИЦЫ STUDIO, а не единый рендер с Gaussian krpano.
В режиме GPU исходная модель отображается 20K-точечным облаком, а не исходными Gaussian-эллипсами.
TOUR, LAB, VIDEO krpano доступны после возврата в Gaussian-режим, не одновременно с GPU MORPH.
Локальные файлы с компьютера нельзя передать ссылкой: используйте публичный HTTPS PLY.
Поведение полного WebGL на компьютере пользователя нужно проверить.

GitHub: загрузить папку logo-test-v49 в VIEWER/.

Открыть GPU MORPH через тот же STUDIO URL: https://3xyzmedia.github.io/VIEWER/logo-test-v49/studio.html?gpu=1&model=SOY2.ply
Режим для зрителя: https://3xyzmedia.github.io/VIEWER/logo-test-v49/studio.html?gpu=1&ui=locked&model=SOY2.ply
