3XyzMedia v10 - REAL LABEL COLOR TEST

Папка для загрузки: VIEWER/logo-test-v10/
В архиве готовая папка, не загружать поверх старой v9.

Изменения:
- На ПК в морфе теперь используется RGB, восстановленный из 3DGS SH DC полей исходного LABEL PLY, согласованный с 2048 точками.
- Существующий исходный цвет модели при 0%, RGB логотипа при 100%.
- Убрана кнопка «Вернуть». «Зеркало» скрыто с прежним значением; не переписывал его в shader.
- Кнопка MORPH поставлена справа от «Глубина».
- Окно MORPH опущено ниже раскрытого фирменного лэйбла; на низких экранах есть страховочная прокрутка, чтобы сохранить нижние кнопки.
- Базовая геометрия/вращение/перемещение/LABEL/SHARE/FIRE/TOUR/BURST/аудио/видео не изменены.
- Mobile продолжает использовать старый облегченный procedural shader (цвет настоящего PLY в мобильном морфе НЕ добавлен).

Ограничение: 2048 RGB записаны прямо в ветвления GLSL, это тест; компиляция на реальном WebGL и точность привязки цветов требуют проверки. Переноса оригинальных 80100 гауссианов с opacity/shape нет.
