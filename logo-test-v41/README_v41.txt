3XyzMedia MORPH v41 — controlled size / correct duration

Версия для папки VIEWER/logo-test-v41
После публикации: https://3xyzmedia.github.io/VIEWER/logo-test-v41/studio.html

Что исправлено:
1. В сцене только float-uniform параметры krpano, нет запрещённого label_color vec3. Уникальный action xyz_fx41_shader и новая папка исключают путаницу с прежней версией.
2. MORPH size регулирует размер сплатов текста внутри рабочего относительного матричного scaling. Диапазон 0.004...0.12, старт 0.065; не используются абсолютные размеры матрицы.
3. При MORPH >0 обычные Splat size и Screen minimum блокируются, рендер морфа фиксирован по общему scale=0.48 и screen minimum управляется только MORPH size (0.1..1.55 px), чтобы левый параметр реально влиял на размер. При MORPH 0 глобальные настройки возвращаются.
4. Ползунок «Длительность MORPH» регулирует ВЕСЬ цикл MODEL -> LABEL -> MODEL: 2.5..12 секунд, по умолчанию 5.0 с.
5. Мобильная рамка горит ровно ~4.5 секунды, потом сворачивается. Отдельной голубой надписи нет.
6. Уменьшена нагрузка CPU: неизменные параметры krpano больше не отправляются каждый кадр, только текущий прогресс анимации.
7. Исходная модель и старый стабильный v40 остаются без изменения.

Проверка: синтаксис всех JS и XML. Дымовой тест интерфейса в Chromium с имитацией krpano прошёл: MORPH блокирует 2 глобальных регулятора, размер MORPH меняет fx_labelsize и AA; при MORPH=0 глобальные настройки восстанавливаются. Компиляция GPU/WebGL со всеми реальными сплатами на устройстве пользователя не проверена.

Файлы: studio.html, logo_morph_v41.js, scene_logo_v41.xml, scene_logo_v41_mobile.xml и ресурсы.
