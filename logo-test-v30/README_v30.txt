Исправлено для ETHER:
* Исходная модель разлетается как объёмный BURST (новые направление, амплитуда и завихрение).
* Исходная модель теряет не только размер, но и альфа-канал в крпано-шейдере.
* На 100% исходная модель должна стать невидимой. Обратный ход восстанавливает её.

MODEL:

  не выдаём поддельную имитацию за реальное преобразование исходной модели.
* Для обычных binary_little_endian / ASCII PLY c xyz v29 sampling сохранён.
