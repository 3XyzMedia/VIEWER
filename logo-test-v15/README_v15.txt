3XyzMedia v15 — REAL SOY2 SPLAT MORPH + MODEL INPUT

В ZIP готовая папка logo-test-v15 для VIEWER/.
На ПК используется сохранённый 4096-target shader из v11/v14.
На смартфоне теперь shader mode 9 ПЕРЕМЕЩАЕТ исходные SOY2 splats (512 цветов/XYZ из настоящего LABEL).
Второго WebGL-слоя и CSS-скрытия модели НЕТ.
Мобильная детализация по-прежнему низкая, ради ограничения нагрузки.
В поле «Модель PLY» укажи SOY2.ply либо имя другой модели в 3XyzMedia/3d-models/main/model, либо абсолютный https URL.
«Загрузить модель» обновляет страницу и сохраняет настройки и URL. Ссылка SHARE передаёт model=.

Важно: `splatshader` требует поддержки крpano/WebGL на устройстве. На Samsung может быть ошибка компиляции/перегрузка. Не удаляй v12. Проверка синтаксиса не равна GPU-тесту.
