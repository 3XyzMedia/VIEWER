3XyzMedia STUDIO v31 — SYNC + COMPRESSED PLY

Что исправлено:
1. ETHER: модель обрабатывается krpano BURST, текст собирается ThreeJS 20K. Оба используют один progress и меняются одновременно, без отдельных часов/таймлайнов.
2. MODEL: читалка PLY теперь понимает не только float x/y/z, но и compressed Gaussian PLY: element chunk с min/max XYZ и element vertex с packed_position. Все элементы PLY учитываются при бинарных смещениях.
3. Исправлена ошибка повторного отображения после асинхронной загрузки PLY: draw() вызывается сразу после успешной загрузки.
4. Модель берётся из того же поля, что использует krpano, а не из встроенного демо.
5. Старый 4K шейдер не используется для сборки текста.

Два режима:
- ETHER: исходная модель растворяется через BURST, надпись 20K собирается из облака.
- MODEL: 20K точек берутся из выбранной PLY и движутся к тем же 20K целевым позициям LABEL. Исходная модель растворяется через BURST.

Ограничения:
- compressed-PLY поддерживается, если присутствуют поля packed_position и chunk min_x/min_y/min_z/max_x/max_y/max_z, упаковка 11-10-11 и блоки по 256 точек. Другие схемы сжатия не декодируются.
- При моделях из внешнего домена требуется CORS.
- Для ETHER/MODEL необходим /VIEWER/plugins/threejs_krpanoplugin.js.
- В мобильном режиме намеренно сохранён неон.
- Реальный браузерный WebGL-рендеринг этой версии не тестировался. Проверены JS синтаксис, XML, архив и тестирование алгоритма PLY по синтетическим данным.
