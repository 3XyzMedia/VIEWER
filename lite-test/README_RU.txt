3XyzMedia — v5, пробный модульный Viewer / STUDIO

1. Рабочий корневой VIEWER НЕ МЕНЯТЬ.
2. Создать /lite-test в репозитории VIEWER. Загрузить туда содержимое архива (без внешней папки).
3. Скопировать лицензионный krpano.js из корня VIEWER в /lite-test/krpano.js.
4. /lite-test/studio.html — редактор. Настроить SOY2, снять галочку «Передать ПОЛНУЮ STUDIO», нажать прежнюю кнопку «Копировать ссылку» (она одна).
5. Ссылка получателя ведёт в /lite-test/index.html?p=... без пульта. В нём TOUR, VIDEO и FX загружаются отдельными модулями только при разрешении STUDIO.
6. /lite-test/?id=soy — заранее подготовленный тестовый пресет SOY2.
7. Включить «Передать ПОЛНУЮ STUDIO» для ссылки на полный пульт.

ОГРАНИЧЕНИЯ: новая ссылка ?p=... не короткая. ?id=... короткий, но требует заранее опубликованного JSON. Новая LITE-сцена поддерживает SOY2. Остальные модели не подменяются. В FX режими 1-5,7 опираются на реальный GLSL; FIRE пока использует упрощённое управление iframe без полного эффекта STUDIO. Погода, космос, звук, музыка, салют, метеоры и интерактивный FX LAB в LITE ещё НЕ поддерживаются. Для них используйте режим STUDIO, пока не перенесены. Для проверки на телефоне сначала загрузите комплект в GitHub Pages.

Не удалять файлы из старого VIEWER. Не использовать Releases.
