3XyzMedia STUDIO v70 — COSMIC UI + LOADING + NEON 20K
Версия: 2026-10-28

ОСНОВА
3XyzMedia STUDIO v69 WITH PLY CONVERTER.
Рабочие коды MORPH 20K, обычного MORPH, FX LAB, TOUR, VIDEO, MUSIC и SHARE сохранены.

ПРАВКИ
1. Центральная индикация загрузки. Цифры берутся из krpano progress.progress (0..100), а не из таймера. Процент может стоять на одном числе при подготовке PLY. Скрытие после onloadcomplete и готовности UI. Альтернативный XML без события скрывается по native progress.
2. i: строка FX упрощена до «запустить эффект».
3. Верхние кнопки получили рамки в стиле LABEL, подсветка только для активных режимов.
4. После завершения MORPH 20K кнопка LABEL/brand сворачивается (class expanded снят).
5. Из LAB убрана кнопка прежнего 2D-текста, mode=7 более не выбирается в LAB. Старый код шейдера не удалён, чтобы не повредить остальные FX.
6. HYPERSPACE в правых настройках: отдельные лучи из центра, количество 25..1200, скорость .2..12x, густота 5..100%. Не изменяет 3D splats.
7. METAL STROBE в правых настройках: частота 0.5..8 Hz, яркость 5..80%, по умолчанию выключен. ВНИМАНИЕ: фоточувствительность. При переключении вкладки автоматически выключается; при reduced motion запрещён. Без автоматического включения по SHARE.
8. Цвета MORPH 20K: оригинальный RGB, красный, неоновый зелёный, синий, фиолетовый, голубой. Цвет передаётся ссылкой gpucolor. Исходная модель не перекрашивается.
9. Ранняя скрытая роль UI: до завершения загрузки нижние студийные кнопки не появляются на мобильном viewer; роль определяется в head.

НЕ СДЕЛАНО/НЕ ДОКАЗАНО
- 20K на смартфоне по-прежнему отключён из-за прошлых крашей.
- Не проверен реальный krpano WebGL2 в пользовательском браузере. Проверены только синтаксис JS, XML, совместимость DOM и комплектность файлов.
- Эффект зеркального шара с цветными отражениями — идея следующей отдельной версии, в эту не вошёл.

ЗАГРУЗКА НА GITHUB
1. Распаковать ZIP.
2. В репозитории VIEWER в корень загрузить папку logo-test-v70.
3. В папку /VIEWER/morph-targets/ заранее класть сгенерированные 20K BIN из комплектного конвертера.
4. На GitHub Pages открыть: https://3xyzmedia.github.io/VIEWER/logo-test-v70/studio.html
5. Проверить на ПК, затем на смартфоне. Не перезаписывать v69.

ПЛАН ПРОВЕРКИ
A. В момент загрузки отображается реальный прогресс и скрывается после готовности модели и интерфейса.
B. На смартфоне не мелькают кнопки LAB, MORPH, 20K до определения роли.
C. Все кнопки сверху имеют рамки, при PLAY/TOUR/VIDEO/MP3/FX подсветка активна.
D. Нажать LABEL, запустить MORPH 20K, дождаться конца, убедиться, что LABEL сворачивается.
E. В LAB нет 3XyzMedia старого текстового FX; BURST, FIRE, прочие прежние на месте.
F. HYPERSPACE: скорость, количество и густота регулируются независимо; FX OFF скрывает слой.
G. METAL STROBE: выключен по умолчанию, выключается при скрытии вкладки. Не включать при чувствительности к вспышкам.
H. Цвета 20K переключаются; по SHARE сохраняется выбранный цвет и target BIN.
