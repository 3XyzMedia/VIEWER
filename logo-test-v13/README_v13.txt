3XyzMedia GPU MORPH v13 — экспериментальный мобильный тест

Архив включает папку logo-test-v13; загружать в VIEWER целиком.

СМАРТФОН:
- Модель krpano остается нетронутой, в том числе её настоящий Gaussian shader.
- По кнопке LABEL работает WebGL GPU-анимация 12 000 точек, выбранных из настоящего LABEL_TEXTURE_RGB_3dgs.ply, с настоящими цветами.
- Переход начинается НЕ из точных координат модели SOY2, а из отдельно сгенерированного пространственного облака-прокси. Это реальный GPU morph point cloud, но НЕ Gaussian-to-Gaussian morph исходных splats krpano.
- Повторное нажатие во время проигрывания прерывает эффект. Автоматическое завершение через 4.5 с.
- GPU overlay компилируется/создается только при первом нажатии на LABEL. Если экспериментальный контекст упадёт, он не должен затронуть WebGL krpano, но аппаратный лимит общих ресурсов всё равно возможен.

ПК: продолжает использовать оригинальный v12 desktop shader — GPU overlay работает только на мобильных.

Данные: real_label_gpu_12000.bin: 12 000 x (3 исходных proxy XYZ + 3 целевых LABEL XYZ + 3 настоящих RGB), 432 000 байт.

ВАЖНО: это безопасный эксперимент на отдельном WebGL-слое, а НЕ подтверждение поддержки sampler2D внутри krpano splatshader и НЕ настоящий morph исходных гауссианов. Для него нужен согласованный доступ к исходным точкам модели и механизм внедрения атрибутов в рендерер.
