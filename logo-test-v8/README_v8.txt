3XyzMedia LOGO MORPH v8 — ПОЛНЫЙ КОМПЛЕКТ

В ZIP содержится ОДНА ГОТОВАЯ ПАПКА logo-test-v8/ со всеми файлами.
Загрузи эту папку в корень репозитория VIEWER. Не смешивай с logo-test-v7.
Адрес после публикации: https://3xyzmedia.github.io/VIEWER/logo-test-v8/studio.html

Изменено только в рамках MORPH:
- Три смещения X/Y/Z, диапазон -150...+150, шаг 0.5 (сценические единицы).
- Смещение осуществляется ПОСЛЕ поворота текста, как у прежнего ползунка Z.
- SHARE: morphox / morphoy / morphheight, дополнительно logoOffsets в общем состоянии.
- Окно уплотнено: 6 ползунков + прогресс, без внутренней прокрутки при обычной высоте окна.
- Две опции зеркало/глубина, кнопки, подписи компактнее.

Сохранено: LAB, LABEL, TOUR, BURST, FIRE, видео, музыка, камера, повороты XYZ.
Файлы крpano.js в архиве нет: используется /VIEWER/krpano.js.
Модель SOY2.ply загружается по прежнему URL.

Особенности: при выборе направления камеры -Y «верх» на экране не совпадает с локальным Z сцены. Три независимых ползунка позволяют выбрать фактическую экранную высоту без изменения осей просмотра.
Не гарантируется отсутствие прокрутки на очень маленьком экране; если физически места нет, окно может перекрывать другие элементы. На мобильном GPU надёжность WebGL не проверена.
